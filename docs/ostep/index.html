Operating Systems: Three Easy Pieces

Remzi H. Arpaci-Dusseau & Andrea C. Arpaci-Dusseau · version 0.90/0.91 (© 2014)

What you'll learn

How an operating system works, built up from three ideas:

  • Virtualization — turning one CPU and one memory into many private ones: processes, scheduling, address spaces, paging.
  • Concurrency — running many things at once correctly: threads, locks, condition variables, semaphores.
  • Persistence — keeping data safe on devices that fail: disks, RAID, file systems, crash consistency, distributed file systems.

Prerequisites: basic C (pointers, malloc, structs), a rough idea of what a CPU, RAM and disk do, and comfort with a Unix shell.
